# P0 外部样本交接清单

状态：待外部 Windows 环境或合法脱敏样本

本清单用于路线 B（Windows Agent）或路线 C（离线导入）的下一次验证。它不要求提交原始微信数据，也不要求把第三方工具安装到本项目服务器。

## 1. 交接前提

- 数据属于提供者本人，或提供者已获得明确授权；
- 使用专用测试账号，不使用重要主账号；
- 不提供手机号、微信号、登录凭据、数据库密钥、二维码或原始微信目录；
- 样本中联系人、会话标题、正文和文件名均已脱敏；
- 能说明来源微信版本、操作系统版本、导出工具名称和版本；
- 样本可以在不联网访问本项目服务器的情况下生成和初步校验。

## 2. 路线 B：Windows Agent 证据包

若验证 Windows Agent，至少记录以下信息，不把原始数据提交到仓库：

| 项目 | 必须记录 |
|---|---|
| Windows | 版本、架构、补丁级别 |
| 微信 | 版本、是否已登录、测试账号是否隔离 |
| Agent | 来源 URL、固定版本/提交、许可证、运行命令 |
| 输出 | 文件清单、记录数量、SHA-256、是否包含媒体 |
| 行为 | 是否修改源目录、是否需要密钥、是否开放网络端口 |
| 重复性 | 同一源数据重复导出是否得到稳定 ID 和可比较结果 |

最低样本必须包含：一个联系人、一个会话、一条文本消息和一个可关联媒体。导出后要关闭或隔离 Agent，确认源目录未被写入，再把导出包交给本项目校验器。

## 3. 路线 C：离线导入包

交接包应符合 [`docs/p0-import-package-draft.md`](./p0-import-package-draft.md)，并先在提供者本地运行：

```bash
python3 tools/validate_import_package.py /path/to/wechat-archive-import-v0
```

提供给项目的内容只包括：

- `manifest.json`；
- 脱敏后的 NDJSON 文件；
- 合成或已获授权的媒体样本；
- 校验器输出；
- 样本生成说明和统计值。

不接受：原始微信数据库、密钥文件、二维码、未脱敏聊天正文、未确认授权的媒体或含有用户目录绝对路径的日志。

## 4. 本项目验收顺序

1. 在隔离目录复制样本，不覆盖现有 Runtime 数据；
2. 运行静态校验器，记录版本和输出；
3. 检查消息、会话、联系人和媒体的引用关系；
4. 对样本做一次完整读取和一次重复读取，比较来源 ID、数量和哈希；
5. 注入一个失败样本，确认错误不会推进 checkpoint；
6. 只有以上证据齐全后，才讨论 P0-12 路线决策和 Phase 1 Fixture Adapter。

## 5. 证据存放边界

仓库只提交本清单、脱敏字段说明、统计值、哈希和人工构造 fixture。原始样本和运行日志存放在仓库外的受控目录，并在验证结束后按提供者要求清理。
