# 部署安全边界

当前部署基线按“单机、自托管、内网优先”设计，不能直接暴露到公网。

## 已实现边界

- Compose 不挂载 `/var/run/docker.sock`，Web/API 不能通过 Docker Socket 任意控制容器；
- `imports/` 以只读方式挂载，API 只接受导入根目录下的相对包名，并拒绝路径穿越和符号链接逃逸；
- 归档媒体只能通过数据库中属于当前账号的附件记录读取，媒体路径必须位于配置的归档根目录内；
- 数据库和媒体写入 `/data`，容器不需要宿主机的其他目录权限。

## 当前限制

- V1 尚未实现用户认证、会话管理、CSRF 防护和 HTTPS 终止；
- 不应将当前 API 直接暴露到公网；建议放在 VPN、内网反向代理或额外认证网关之后；
- 日志和错误响应仍可能包含导入校验错误，接入公网前需要完成脱敏策略和认证任务。
