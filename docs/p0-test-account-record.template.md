## 测试数据准备

- [ ] 至少一个联系人

- [ ] 至少一种媒体消息
- [ ] 已确认允许在本地测试环境读取这些数据
- [ ] 已确认不会把原始数据提交到 Git

- [ ] 没有在仓库、Issue、日志或截图中记录密码/密钥
